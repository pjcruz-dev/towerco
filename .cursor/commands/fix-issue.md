# Fix issue

Fix the issue I describe or link after this command.

1. Read it (if I gave a number and `gh` is installed, use `gh issue view <number>`).
2. Reproduce with a failing test first. If that is impossible, say why.
3. Find the root cause and fix it at the right layer (not a UI workaround for a backend bug).
4. Search for the same flaw elsewhere and mention it.
5. Run lint, types and tests and report the results.
6. Summarize: cause, fix, test added, follow-ups.
