# Command palette and navigation

Use the sidebar for browsing and the command palette for fast jumps to pages and records.

## Prerequisites

- You are signed in to the tenant workspace.
- You have permission to open the destination page or record.

## Steps

1. Browse with the **left sidebar** (Operations and Administration groups).
2. Open the command palette with `Ctrl+K` (Windows) or `Cmd+K` (macOS).
3. Type a page name (for example “Tickets” or “Sites”) and press Enter.
4. Type a record identifier (site code, ticket number, document number) to search entities when search is available.
5. Use browser back or breadcrumbs to return without losing your place when possible.

## Expected result

You reach the intended page or record in one or two keystrokes instead of hunting through menus.

## Common errors

- **Result missing** — you may lack permission, the module may be disabled, or the query is too short.
- **Palette does nothing in an input field** — focus may be in a form field; click outside or use the header control if available.
- **Wrong tenant** — confirm you are on the correct tenant hostname.
