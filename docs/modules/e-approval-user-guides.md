# E-Approval — End-user guides (start here)

Choose the guide that matches your role. Both start with **login** and use simple step-by-step instructions.

### In the app (preferred)

After deploy + seed:

1. Open **E-Approval → Help** (or `/help`)
2. Or click **Help** on Submissions / Approvals
3. Admins edit anytime: **E-Approval → Settings → User guides**

| I am a… | Open this guide |
|---------|-----------------|
| **Normal user / requestor** — I fill forms and submit requests | [Guide for requestors](./e-approval-guide-requestor.md) |
| **Approver** — I approve, reject, or send requests back | [Guide for approvers](./e-approval-guide-approver.md) |
| **Both** | Read the requestor guide first, then the approver guide |
| **Need one long reference** | [Full end-user guide](./e-approval-end-user-guide.md) |

### Example login

- `https://staging.alliancetowers.com/login`  
- Or your company workspace URL ending in `/login`

### Quick training (two people)

1. **Requestor:** follow [Guide for requestors](./e-approval-guide-requestor.md) → submit a test request → note the document number.  
2. **Approver:** follow [Guide for approvers](./e-approval-guide-approver.md) → save signature → open **Approvals** → approve (or request revision).  
3. If revision: requestor resubmits → approver decides again → status **Approved**.
