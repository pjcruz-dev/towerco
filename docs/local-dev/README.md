# Local Windows launchers

Optional `.cmd` helpers for local Docker/Podman development on Windows.

Day-to-day prefer root `npm run` scripts (`npm run dev`, `npm run dev:down`, `npm run dev:logs:api`, …).

Run from repo root, for example:

```bat
docs\local-dev\tower.cmd
docs\local-dev\dev.cmd
```

These scripts are **not** included in AWS production images.
